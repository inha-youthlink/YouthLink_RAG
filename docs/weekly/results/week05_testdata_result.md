## 3. 대표 사례

### 목록 질문에서 정책 누락 (L1)
- 질문: "주거 관련 지원 정책 전부 알려줘"
- 검색 결과(top-10): 구직활동 응원금(0.473), 주거 상담 센터(0.440), 자립준비청년 정착 지원(0.433), 이사비(0.427), 월세(0.414), 대중교통비(0.412), 전세보증금 대출 이자(0.386), 직업훈련 수강비(0.382)
- **청년 공공임대주택 입주자 모집**이 검색 결과에 없음. LLM은 근거 안에서만 답하므로 누락을 알 수 없음
- 답변: "근거에 있는 주거 관련 정책은 5개예요" → 월세, 이사비, 전세 이자, 상담 센터, **자립준비청년 정착 지원(복지)**

### "두 번째 거"를 임의로 해석 (F2)
- 질문: "두 번째 거 자세히 알려줘" (앞 대화 없음)
- 답변: "청년 1:1 취업 컨설팅은 이력서와 자기소개서 작성, 모의 면접을 ..."
- 같은 맥락의 F1("그 정책 신청 서류 뭐 필요해?")은 되물었지만, F2는 근거 목록의 순서를 기준으로 정책을 골라 답함

### 관련 정책이 없을 때 점수가 더 높음 (N1, N2)

| 질문 | 관련 정책 | 검색 1위 점수 |
|---|---|---|
| 군 복무 중인 청년 지원 정책 있어? (N2) | 없음 | **0.519** |
| 청년 반려동물 양육비 지원 있어? (N1) | 없음 | **0.493** |
| 주거 관련 지원 정책 전부 알려줘 (L1) | 있음 | 0.473 |
| 지금 신청 가능한 일자리 정책만 알려줘 (L2) | 있음 | 0.440 |
| 오늘 날씨 어때? (O1) | 없음 | 0.182 |

관련 정책이 없는 질문의 점수가 관련 정책이 있는 질문보다 높은 경우가 있어, **고정 점수 기준으로는 "관련 정책 없음"을 판정할 수 없음**

## 4. 6주차 이후 설계에 주는 의미

| 발견 | 필요한 처리 | 우선순위 |
|---|---|---|
| 후속 질문에서 "두 번째 거"를 임의 해석 (F2) | 질문 분석: 질문 재작성 + 정책 지목 (직전에 보여준 목록) | **6주차** |
| 목록 질문에서 벡터 검색이 정책을 누락 (L1) | 정책 목록 유형: 분야 조건 SQL 조회 | ~8주차 |
| 관련 없는 질문의 점수가 관련 질문보다 높음 (N1, N2) | 관련성 판정: LLM 판정 또는 리랭커 (고정 임계값 불가) | ~8주차 |
| 단순한 숫자 조건은 LLM도 정확히 비교 (E1, E2) | 자격 확인 코드 판정은 필요하나, 복합 조건 데이터로 추가 확인 후 우선순위 결정 | ~8주차 |
| 범위 밖·판단 불가는 프롬프트만으로 대부분 처리 (O1, O2, U1) | 범위 밖 유형은 검색·LLM 호출 절약 목적으로 분리 | 6주차 (간단) |

## 5. 프롬프트 개선 후보 (`generate_v2`)

- 굵은 글씨 사용 (C2): 형식 규칙이 지켜지지 않음
- "근거" 내부 용어 노출 (L1, N1): "공고"로 표현하도록
- 관련 정책이 없을 때 관련 없는 담당 기관 안내 (N2)
- 되묻는 상황에서 정책을 길게 나열 (U2), 목록 답변이 김 (L1 출력 1,073토큰, 14.0초): 정책당 분량 기준 필요
